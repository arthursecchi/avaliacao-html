# Academia e Musculação para Iniciantes

Avaliação HTML

## Páginas
- index.html: apresentação e dicas básicas
- treino.html: organização do treino
- exercicios.html: exercícios e remada aberta
- formulario.html: formulário de registro de treino

## Tecnologia
HTML5.

## Como abrir
Abrir o arquivo html/index.html no navegador.

## Vídeo
Os vídeos estão em video/remada aberta.mp4 e video/puchada alta.mp4 e aparecem em treino.html e exercicios.html.

## Requisitos usados
Menu de navegação, tags semânticas (header, nav, main, section, article, aside, footer), tabela 3x3 com colspan, formulário (date, range, datalist, required, placeholder), details/summary, figure/figcaption, abbr, mark, del, ins, blockquote, cite, progress, meter, time, vídeo local e comentários HTML.
